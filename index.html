How direct Ethernet works (2 PCs, one cable)
Connect the machines with an Ethernet cable (modern network adapters usually auto-negotiate). They need compatible local IP addresses on the same subnet, whether assigned automatically or configured manually. This app offers host candidates only and does not configure STUN/TURN servers. Direct connection still depends on browser ICE behavior, OS firewall rules, and network interface selection; success is not guaranteed on every device.

If it doesn't connect: check the OS firewall (allow the browser on the relevant Private network), confirm both interfaces have compatible addresses, and inspect the Diagnostics panel. The data path should use a selected host-to-host candidate pair; the diagnostics panel lists local candidates only.
